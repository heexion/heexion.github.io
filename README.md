## Projects

### InningLog

- PM · Web Lead
- Google OAuth 로그인 및 온보딩 구현
- 프로필·친구·알림·타임라인 API 연동
- FCM 기반 웹 푸시 알림 등록
- PWA와 Firebase Service Worker 충돌 해결

> 현재 개발 중이며 일부 화면과 기능은 구현 및 연동을 진행하고 있습니다.

### ORE

전자·가전제품의 등록, 보증과 수리 정보를 제품 단위로 연결하는 제품 생애주기 관리 서비스입니다.

- PM · Web Developer
- 1·2차 MVP 기능 범위 및 우선순위 설정
- 제품 등록·상세 조회 중심의 1차 MVP 개발
- Zustand 기반 상태 관리 및 Axios API 연동
- 챗봇 세션·메시지 상태와 자동 스크롤 구현
- 가족 관리·판매 지원·소유권 이전 기능 기획

> 현재 1차 MVP를 개발 중이며 2차 MVP 기능은 기획 단계입니다.

- 아이디어 작성·채택·거절 흐름 구현

- TanStack Query 기반 목록과 무한 스크롤 처리

### 냠코치

식단과 운동을 기록하고 목표에 따른 개인화 피드백을 제공하는 Native Android 앱입니다.

- Android Lead
- 소셜 로그인 및 온보딩 흐름 구현
- 사용자 정보 서버 전송 및 앱 권한 처리
- 식단·운동 데이터 예외 상황 대응
- 주요 기능 통합 QA 및 개발 일정 관리
